# مركز التحميل الذكي — نسخة أندرويد (بدون سيرفر)

التطبيق يشغّل ملف `main1.py` (Flask) داخل الهاتف نفسه عبر Chaquopy،
وواجهة WebView تفتح `http://127.0.0.1:5000`. لا يحتاج أي سيرفر خارجي.

## بناء الـ APK من GitHub Actions
1. أنشئ مستودعاً جديداً على GitHub وارفع **كل محتويات هذا المجلد** (بما فيها `.github`).
2. افتح تبويب **Actions** ← **Build APK** ← **Run workflow** (أو يبدأ تلقائياً عند أول push).
3. بعد انتهاء البناء (حوالي 5–10 دقائق) نزّل الملف `SmartDownloader-apk` من أسفل صفحة التشغيل (Artifacts)،
   فك الضغط ثم ثبّت `app-debug.apk` على هاتفك (فعّل "التثبيت من مصادر غير معروفة").

## ملاحظات
- رمز الدخول الافتراضي: `125678` (يمكن تغييره من الإعدادات داخل التطبيق).
- الملفات المحمّلة تُحفظ داخل التطبيق. اضغط تحميل على أي ملف في تبويب الملفات
  أو زر التحميل في الأدوات لنسخه إلى `التنزيلات/SmartDownloader` على الهاتف.
- لا يوجد ffmpeg على أندرويد، لذلك يُحمَّل الفيديو بصيغة جاهزة (ملف واحد صوت+صورة)،
  وقد تكون الجودة العالية (1080p/4K) غير متاحة في بعض المواقع، و"صوت فقط" يُحفظ بصيغة m4a/webm بدل mp3.
- التطبيق يشغّل خدمة في الخلفية (إشعار دائم) كي لا تتوقف التحميلات عند الخروج منه.
- إذا فشل أي موقع بعد فترة، حدّث yt-dlp بإعادة بناء الـ APK (يُسحب أحدث إصدار تلقائياً).
